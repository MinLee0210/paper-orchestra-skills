# Bundled conference templates

The CVPR 2025 and ICLR 2025 bundles are copied from Google Research's
[PaperOrchestra](https://github.com/google-research/paper-orchestra) repository
(Apache-2.0). The style files (`*.sty`, `*.bst`) are the official venue files
distributed with each conference's author kit and remain subject to their
original terms. The `guidelines.md` summaries are derived from the official
author kits.

The `ieeeconf` scaffold uses the standard `IEEEtran` class from the TeX
distribution. The `arxiv` scaffold is a neutral one-column preprint layout and
is not an official arXiv style. Neither bundles third-party style files.

The skills in this repository do not modify the style files. If you add a
venue, keep its copyright headers intact.
